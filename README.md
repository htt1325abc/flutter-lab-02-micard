# Lab 2: MiCard

## Mô tả

MiCard là danh thiếp số hiển thị thông tin cá nhân theo bố cục Material. Thông tin được đặt trong các hằng số để dễ thay đổi và giải thích.

## Chức năng

- Hiển thị avatar và họ tên sinh viên
- Hiển thị vai trò Flutter Developer
- Hiển thị số điện thoại và email dạng placeholder

## Công nghệ

- Flutter
- Dart

## Cách chạy

```bash
flutter pub get
flutter run
```
